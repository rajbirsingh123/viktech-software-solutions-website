FAQ

Common questions

We already have a Next.js website - does that help?

Often, yes. Shared types, API clients, and business logic can frequently move between a Next.js app and a React Native app, which cuts down duplicate work.

Do you use Expo or bare React Native?

We default to Expo for faster iteration and simpler builds, and drop to bare React Native only when a project needs a native module Expo doesn't support.
